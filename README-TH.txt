ไฟล์เว็บไซต์ Thailand Amazing Xiangqi

ภายใน ZIP มี:
- index.html: หน้าเว็บที่เรียก Ruffle เพื่อเปิดไฟล์ Flash
- Thailand Amazing Xiangqi.swf: ไฟล์นาฬิกาต้นฉบับ

วิธีเผยแพร่ฟรีด้วย GitHub Pages:
1. สมัคร/เข้าสู่ระบบ https://github.com/
2. สร้าง repository ใหม่ ตั้งชื่อ เช่น thailand-amazing-xiangqi
3. เลือก Public
4. อัปโหลดไฟล์ทั้ง 3? (index.html และไฟล์ .swf; README นี้ไม่จำเป็น)
5. เข้า Settings > Pages
6. ใน Build and deployment เลือก Deploy from a branch
7. เลือก Branch: main และ Folder: /(root) แล้วกด Save
8. รอให้ GitHub แสดง URL เว็บไซต์ในหน้า Pages

หมายเหตุ:
- Ruffle เป็นตัวจำลอง Flash ในเว็บ ไม่ใช่ Flash Player เดิม
- ยังไม่ได้ยืนยันว่า SWF นี้ทำงานครบทุกฟังก์ชันบน Ruffle หรือทุกมือถือ
- หากไฟล์เดิมเรียกบริการภายนอก/ใช้คำสั่ง Flash ที่ Ruffle ยังไม่รองรับ อาจต้องปรับเพิ่มเติม
- เว็บไซต์ GitHub Pages แบบ Public จะเปิดให้คนทั่วไปเข้าดูได้
